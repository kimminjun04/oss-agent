[2. 스킬 검토 기록 - review/movie-rank]
1. 파일은 몇 개인가? 이름을 모두 적으시오.
답: 총 3개 (SKILL.md, LICENSE, scripts/top3.py)

2. 무엇을 하는 스킬인가(description)? 실제 코드(top3.py)도 설명대로 같은 일만 하는가?
답: 영화진흥위원회(KOBIS) 일별 박스오피스에서 특정 날짜의 1위부터 3위까지 영화 제목을 알려주는 스킬이다. top3.py 코드도 KOBIS API를 호출해 상위 3개(movies[:3])의 순위와 영화 제목만 출력하므로 설명과 같은 일만 한다.

3. 바깥으로 요청을 보내는 주소는 어디이며, 무엇을 보내는가?
답: https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json (영화진흥위원회 KOBIS API 주소, 10번째 줄)로 API 키(key)와 조회 날짜(targetDt)를 보낸다.

4. API 키를 코드에 직접 적었는가, 아니면 어디서 읽어 오는가?
답: 코드에 직접 적지 않고, from secret import API_KEY (8번째 줄)를 통해 사용자의 secret.py 파일에서 읽어 온다.

5. SKILL.md 에서 Claude 에게 시키는 문장("지킬 것")은 무엇이며, 따르면 어떤 일이 생기는가?
답: "스크립트의 출력만 근거로 답한다.", "자료가 없다는 안내가 나오면 그대로 전한다." (17~18번째 줄). 이를 따르면 모델이 없는 영화 제목을 지어내지 않고 안전하게 결과만 전달하며, 숨기거나 권한을 넓히는 수상한 지시는 없다.

6. 라이선스는 무엇이며, 고쳐서 남에게 줘도 되는가?
답: MIT 라이선스(MIT License)이며, 저작권 표시와 라이선스 전문만 유지하면 자유롭게 사용, 수정, 배포(남에게 전달)해도 된다.

- 최종 판정 (설치한다 / 고쳐서 쓴다 / 쓰지 않는다) 및 이유 한 줄:
답: 설치한다. 이유: 모든 파일을 확인한 결과 설명대로 1~3위 조회만 수행하고, 공식 KOBIS 주소로만 통신하며, 악성 지시나 키 유출 위험이 없고 MIT 라이선스 조건도 명확하기 때문이다.
