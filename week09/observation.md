# 9주차 실습 관찰 기록

## 1. 도구 호출 순서 (3~4단계)
1. PowerShell - 폴더 내 파일 목록 확인 (List all files)
2. Read - average_pandas.py
3. Read - average_plain.py
4. Read - check.py
5. Read - scores.csv
- 도구를 쓴 횟수: 5회
- 읽은 파일 수: 4 / 4

## 2. 네 파일 설명 확인 (5단계)
| 파일 | O/X | 틀렸다면 무엇이 (확인 내용) |
| :--- | :---: | :--- |
| scores.csv | O | 학생 성적 데이터 파일이며 결측치(빈 값)와 문자열 오류가 포함되어 있음을 정확히 설명함 |
| average_plain.py | O | 기본 파이썬 문법으로 분류별 평균 점수를 계산하는 코드임을 설명함 |
| average_pandas.py | O | pandas 라이브러리를 사용해 분류별 평균을 구하는 코드임을 설명함 |
| check.py | O | 첫 줄 주석은 '분류별 평균 계산'이라고 되어 있으나, 실제 코드는 점수가 비어 있거나 숫자가 아닌 학생을 찾아 출력한다는 점을 정확히 구분해 설명함 |

## 3. 원본(tools.py)과 사본(tools_nodoc.py) 설명 비교 (7~8단계)
| 비교 항목 | 원본 (주석 있음) | 사본 (주석 없음) |
| :--- | :--- | :--- |
| 받는 값의 형식 | "20260824" 형태의 8자리 날짜 문자열(date), 영화 제목 문자열(title) | KOBIS API targetDt 파라미터로 전달되는 YYYYMMDD 형식의 날짜 문자열(date), 영화 제목 문자열(title) |
| 예시 값 | date: "20260824", 반환 예시: "오디세이" 등 docstring에 적은 예시를 그대로 제시함 | 명시적인 예시 값은 없거나 API 파라미터 형식(YYYYMMDD)으로만 추론해 설명함 |
| 돌려주는 것 | 1위 영화 제목 문자열 / 콤마가 포함된 관객 수 문자열 또는 순위 없음 안내 문구 | movies[0]["movieNm"]을 통한 1위 영화 제목 문자열 / 포맷팅된 관객 수 문자열 또는 안내 문구 |
| 틀리거나 애매한 부분 | 없음 (docstring 내용을 바탕으로 정확히 일치함) | 주석이 없어도 함수 이름과 KOBIS API 파라미터 구조, 코드 흐름을 읽고 정확히 추론함 |

## 4. README.md에서 사실과 다른 곳 또는 확인한 점 (11단계)
- 무엇을 하는 코드인지(`tools.py`, `main.py` 역할), 무엇을 설치해야 하는지(`pip install -r requirements.txt` 및 `secret.py`에 `API_KEY` 설정), 어떻게 실행하는지(`python main.py`) 세 가지 항목이 모두 포함됨.
- 실제 실행해보지 않았음에도 코드 내 문자열을 바탕으로 동작을 설명하거나, `secret.py` 파일을 별도로 만들어야 한다는 점을 설치 단계에 함께 안내함.
